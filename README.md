# F.A.T.A.L. Character Creator
*Speeds up the character creation process from 11 hours to just a minute!*

## Disclaimer
This is a heavy work in progress.

F.A.T.A.L. is an boardgame with plenty of obscene elements, some of which violates
the CodeBerg ToS. As such, these elements will be either named differently, used diffently,
or not included at all. 

The author does not condone any of the elements in F.A.T.A.L., this is simply
an exercise to write a program for what is possibly the most
convoluted and cumbersome character creation processes known to boardgame
history.
